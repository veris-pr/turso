# HOWTO — docs/storage

This tree documents the storage module. The index of planned docs (with status)
lives in [README.md](README.md); the quadrant folders each carry their own
HOWTO with quadrant-specific rules.

Workflow for any new doc:
1. Decide the quadrant by what the *reader* is doing:
   learning by doing -> tutorials/ · getting a task done -> how-to/ ·
   looking something up -> reference/ · understanding -> explanation/.
   If a draft mixes quadrants, split it.
2. Add/find its row in [README.md](README.md), write it in the quadrant
   folder, flip the status.
3. House rules live in [../README.md](../README.md) (In-Turso sections,
   scope ledgers, same-commit reference updates).

Doc deliverables per phase are listed in [../../PLAN.md](../../PLAN.md) —
a phase is not done while its docs are missing.
