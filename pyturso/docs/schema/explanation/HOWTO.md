# HOWTO — schema/explanation

Understanding-oriented discussion: why it is designed this way, what the
alternatives were, how the pieces relate. These are the project's end goal —
the banked understanding.

The work:
1. Source material: the **questions you logged while reading the Rust**
   (PLAN.md working-method step 1). An explanation doc answers a real
   question you actually had.
2. Draw the diagrams. If it cannot be drawn, it is not yet understood.
3. **Mandatory closing section — "In Turso":** links to the Rust files, what
   pyturso ports faithfully, what it simplifies, and what the Rust does that
   pyturso does not. This section is the bridge to Rust fluency.
4. Re-read the Rust after your Python version works and update this doc with
   what you missed (PLAN.md working-method step 5).
5. Flip the status in [../README.md](../README.md).
