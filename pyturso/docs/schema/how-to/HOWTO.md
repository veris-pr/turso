# HOWTO — schema/how-to

Task recipes for someone in the middle of work: goal-form titles
("Diff bytecode against tursodb"), minimal context, straight to the steps.
Unlike tutorials, they assume competence and address a real task, not learning.

The work:
1. Notice yourself re-deriving a procedure for the second time — that is the
   trigger; add it to the table in [../README.md](../README.md) if missing.
2. Write the recipe: goal, preconditions, numbered steps, how to check it
   worked, common failure modes.
3. Keep it short. If you are explaining *why*, cut it and link the
   explanation doc.
4. Flip the status in ../README.md.
